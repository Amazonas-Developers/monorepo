CLIENTES WINDOWS (PerimetralesView) — conexión al servidor de IA
================================================================

abrir_puertos_cliente.bat
  Ejecutar UNA vez en CADA computadora cliente (doble clic; pedirá
  permiso de administrador). Permite la salida del firewall hacia el
  servidor y PRUEBA la conexión, diciéndote si el cliente lo alcanza.

  Si el servidor tiene otra IP, edita la línea  set "SERVIDOR=..."  del .bat.

Pasos para poner un cliente a funcionar:
  1) Copia esta carpeta a la computadora cliente.
  2) Doble clic en abrir_puertos_cliente.bat (acepta el permiso de admin).
  3) Si dice "TODO OK", abre PerimetralesView y conéctalo a:
        ws://72.68.60.141:9000/ws
     (edita el .env junto al .exe si aún apunta a la IP vieja 72.68.60.171).

Nota: lo que casi siempre bloquea la conexión NO es el cliente, sino el
firewall del SERVIDOR Linux. Si el .bat reporta puertos que no se alcanzan,
en el servidor ejecuta una vez:
    sudo ufw allow 9000/tcp && sudo ufw allow 8090/tcp && sudo ufw allow 8091/tcp
